Latest version: 0.10.0

Getting the latest version

BX Designs is shared by BuildX Multimedia. Ask us for the latest installer folder, then run Install BX Designs.cmd inside it. Installing over an older version keeps your settings.

In the app, Help › Check for Updates tells you when a new version is out.

What's new

  • Faster painting with big soft brushes.
  • JPEG Options when saving a JPEG: quality and Baseline, Optimized or Progressive.
  • Help › Check for Updates, recently used fonts at the top of the font menus, Camera Raw defaults.
  • Template store: open templates from this site straight into BX Designs.
